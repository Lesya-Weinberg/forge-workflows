# Deliver profile — Full

New product / subsystem / regulatory scope. Maximum depth and scrutiny.

Everything in Meticulous, plus: `reviewer` includes a security validation pass; `tester` adds an
accessibility audit and full performance suite; `devops-engineer` uses blue-green or progressive
delivery; `sre` adds chaos-readiness; `technical-writer` updates the knowledge base;
`scrum-master` produces a full sprint-review, retrospective, and risk register and feeds
`insights.md`.

**Gate policy is typically `review-all`.** Every hard gate is enforced. Expect multi-session
sprints; close every session with a full `sprint-state.md` and `development-state.md` rewrite so a
cold session can resume exactly where this one stopped.
